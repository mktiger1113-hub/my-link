# 마이링크 (My Link) 제품 요구사항 정의서 (PRD)

## 1. 프로젝트 개요
- **프로젝트명**: 마이링크 (My Link)
- **목적**: 닉네임이 곧 웹사이트 주소가 되는, 세상에서 가장 간편한 링크 통합 서비스
- **브랜드 컨셉**: "꾸미지 않아도 세련된, 리스트 중심의 미니멀리즘"

---

## 2. 핵심 기능

### 2.1 필수 기능
| 구분 | 기능명 | 상세 설명 |
| :--- | :--- | :--- |
| **인증** | Firebase Google 로그인 | Google 계정 기반 가입/로그인 |
| **URL** | 닉네임 기반 URL | `displayName`이 URL 경로가 됨 (예: `mylink.io/mktiger`) |
| **편집** | **인라인 편집 (Inline Edit)** | 프로필(이름, 소개)과 링크 정보를 페이지 이동 없이 목록에서 바로 수정 |
| **프로필** | 프로필 관리 | 표시 이름(`username`), 아이디(`displayName`), 한 줄 소개 수정 기능 |
| **링크** | 링크 관리 | 링크 제목, URL 추가 및 삭제 (목록 내 인라인 수정 포함) |
| **아이콘** | Google 파비콘 API | Google Favicon API를 사용하여 입력된 URL의 파비콘을 아이콘으로 자동 표시 |
| **랜딩** | 공개 리스트 페이지 | 지정된 닉네임 주소로 접근 시 나오는 링크 리스트 페이지 |

### 2.2 제외 및 제약 사항
- **이미지 업로드 기능 없음**
- 링크 활성화/비활성화 전환 기능 없음
- 링크 드래그 앤 드롭 및 수동 순서 변경 기능 없음
- **디자인 테마 선택 기능 없음** (단일 미니멀 디자인)
- 관리자 페이지 내 모바일 뷰 미리보기 기능 없음

## 3. 기술 상세 사양

### 3.1 회원 가입 및 URL 정책
- **초기값 설정**: 구글 로그인 시 제공되는 **이메일 주소의 로컬 파트(Local Part, @ 앞부분)**를 추출하여 사용자의 `displayName` 초기값으로 자동 설정.
- **URL 정제**: 이메일 아이디에 포함된 특수문자(`.`, `+` 등)는 URL 안정성을 위해 자동으로 제거하거나 안전한 문자로 치환 처리함.
- **슬러그 활용**: 설정된 `displayName`은 즉시 공개 페이지의 URL 경로(Slug)로 사용됨.
- **중복 제어**: URL로 사용되므로 닉네임은 시스템 내에서 유일해야 함 (중복 시 가입 단계 혹은 수정 시 별도 처리 필요).

### 3.2 데이터베이스 (Firestore 모델링)
- **구조**: `users` 컬렉션 내 사용자 문서, 그 아래 `links` 서브 컬렉션.
- **필드**:
  - `users/{uid}`
    - `displayName`: (string, 필수, unique) URL 경로로 사용될 고유 아이디
    - `username`: (string, 필수) 페이지 상단에 노출될 실제 사용자 이름
    - `bio`: (string) 사용자 소개
  - `users/{uid}/links/{linkId}`
    - `title`: (string) 링크 제목
    - `url`: (string) 링크 URL
    - `createdAt`: (timestamp) 등록일 (목록 정렬 기준)

### 3.3 아이콘 자동화 (Google API)
- `https://www.google.com/s2/favicons?domain={url}&sz=64` 형태의 API를 활용하여 클라이언트 단에서 즉시 렌더링.

### 3.4 UI 디자인 (shadcn/ui)
- `shadcn/ui`를 사용하여 인라인 텍스트 필드, 버튼, 알림창(Toast) 등을 깔끔하게 구현.
- 별도의 테마 기능 없이 블랙 & 화이트 중심의 모던한 단일 디자인 유지.

## 4. 사용자 여정
1. **로그인**: 구글 계정으로 로그인 (이메일 앞부분이 `displayName`으로 자동 설정됨).
2. **정보 확인**: 자동 설정된 `displayName`과 `username`을 확인하고 필요 시 인라인으로 수정.
3. **링크 추가**: 인라인 입력창에 제목과 URL을 넣고 추가.
4. **인라인 수정**: 오타가 있다면 해당 텍스트를 클릭하여 즉시 수정.
5. **공유**: `mylink.io/아이디` 주소를 SNS에 게시.
