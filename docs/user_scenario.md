# 마이링크 (My Link) 사용자 시나리오 (상세 버전)

본 문서는 마이링크 서비스에서 발생할 수 있는 모든 사용자 경험 시나리오를 기술합니다.

---

## 1. 방문자 시나리오 (Public Page)

### 1.1 정상 접속 및 탐색
- **방문자**는 운영자의 정보를 확인하기 위해 **공유받은 유효한 URL로 접속한다.**
- **방문자**는 정체성을 파악하기 위해 **상단의 `username`, `bio`를 확인한다.**
- **방문자**는 운영자의 다른 채널로 이동하기 위해 **나열된 링크 아이템 중 하나를 클릭한다.**
- **시스템**은 데이터 분석을 위해 **링크 클릭 시 해당 링크의 '클릭 조회수'를 1 증가시킨 뒤 외부 사이트로 연결한다.**

### 1.2 예외: 존재하지 않는 페이지 접속
- **방문자**는 주소를 잘못 입력하거나 삭제된 프로필의 **유효하지 않은 URL로 접속한다.**
- **방문자**는 길을 잃지 않기 위해 **"존재하지 않는 페이지" 안내(404 에러)와 함께 메인 페이지로 이동하는 버튼을 확인한다.**

---

## 2. 소유자 시나리오 (Admin)

### 2.1 가입 및 초기화
- **소유자**는 서비스를 시작하기 위해 **구글 계정으로 인증을 진행한다.**
- **시스템**은 편의를 위해 **지메일 아이디의 특수문자를 정제하여 `displayName`의 초기값으로 자동 설정한다.**
- **소유자**는 기본 정보를 완성하기 위해 **인라인 편집 기능을 이용해 `username`과 `bio`를 입력한다.**

### 2.2 닉네임(displayName) 변경 및 중복 확인
- **소유자**는 고유 URL을 변경하기 위해 **인라인 영역에서 `displayName`을 수정한다.**
- **소유자**는 변경하려는 아이디가 이미 사용 중인지 확인하기 위해 **수정 완료 시 시스템의 실시간 중복 검사 피드백을 확인한다.**
- **소유자**는 중복된 아이디일 경우 **"이미 사용 중인 이름입니다"라는 경고 메시지를 확인하고 다른 이름을 입력한다.**

### 2.3 링크 관리 및 유효성 검사
- **소유자**는 새로운 정보를 공유하기 위해 **제목과 URL을 입력하여 링크를 추가한다.**
- **소유자**는 실수로 잘못된 주소(예: `httttp://...`)를 입력했을 때 **시스템의 URL 유효성 검사 경고를 확인하고 올바른 주소로 수정한다.**
- **소유자**는 링크 편집 과정에서 **오타를 클릭 한 번으로 즉시 수정(인라인)하고 변경 사항이 즉시 웹에 반영됨을 인지한다.**

### 2.4 성과 확인 (조회수)
- **소유자**는 어떤 링크가 인기가 많은지 파악하기 위해 **자신의 관리 화면에 표시된 각 링크별 '클릭 조회수' 숫자를 확인한다.**

### 2.5 로그아웃 및 세션 관리
- **소유자**는 개인정보 보호를 위해 **설정 메뉴에서 로그아웃을 수행한다.**
- **소유자**는 로그인 유지가 만료되었을 때 **다시 관리 페이지에 접근하기 위해 가이드에 따라 재로그인을 진행한다.**
